About Gallery 128

This is a Parallax-built compact gallery shell inspired by early monochrome graphical computers. It does not reproduce original system software, logos, fonts, or copyrighted interface assets.

Its role is curatorial: posters, visual design, project exhibitions, and honest placeholders for artifacts that still need to be located and published.
