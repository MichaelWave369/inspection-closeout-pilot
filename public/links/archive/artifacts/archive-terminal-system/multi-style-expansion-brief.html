PARALLAX ARCHIVE · PUBLICATION PACK

Multi-Style Terminal Expansion

The design rule that allowed the archive to grow from one retro computer into six distinct entry points without cloning project data.

Boundary: this is a curated public brief. Historical inspiration is used as an interaction language, not as a claim of firmware or hardware emulation.

Core rule

A shell changes presentation, not canonical truth. Project identity, status, artifacts, relationships, evidence boundaries, and public URLs remain owned by Archive Core.

Six roles

IBM 5100 — Discovery: catalog, tape, research-terminal restraint, and museum-like mystery.

SL1200 — Origin: personal-computing memory, DOS commands, DeskMate, and autobiographical beginnings.

PAT Mk.1 — Creation: Fieldglass, Graph Cinema, Ledger, Witness Light, and visible dissent.

Breadbox 64 — Play: games, music, experiments, programs, and creative energy.

Gallery 128 — Gallery: posters, visual work, exhibitions, and curator inspection.

Field Luggable — Deployment: infrastructure, practical builds, evidence, and operator-ready framing.

Adapter contract

Each shell receives canonical records and transforms only labels, navigation metaphors, layout, and interaction. A project may appear as a tape, file, node, program, exhibition piece, or mission package, but all six resolve the same stable project ID.

Historical boundary

The archive uses original Parallax interfaces inspired by recognizable eras and machine forms. It does not distribute ROMs, firmware, logos, manuals, system software, or copyrighted interface assets from the historical products.

Expansion discipline

A new terminal is accepted only when it adds a genuinely different visitor role. Cosmetic reskins are rejected because they increase maintenance without improving understanding.
