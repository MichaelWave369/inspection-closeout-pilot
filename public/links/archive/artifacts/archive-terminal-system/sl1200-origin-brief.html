PARALLAX ARCHIVE · ORIGIN SHELL

SL1200 Origin Edition

A warm home-computing doorway built around the emotional truth of a first personal computer and the worlds waiting behind a blinking cursor.

Memory boundary: SL1200 is the personal name of the edition. The documented Tandy 1000 SL/2 provides the historical authenticity baseline without claiming that memory is a perfect hardware photograph.

Role

The Origin edition connects today’s Parallax work to the beginning of Michael’s relationship with computing. It is less museum-like than IBM and more intimate: a desk, a familiar prompt, and a machine that feels worth lingering inside.

DOS and DeskMate

The shell supports HELP, DIR, PROJECTS, OPEN, TYPE, ARCHIVE, ABOUT, NETWORK, CLEAR, and EXIT. DeskMate provides a graphical home for project files, games, builds, media, music, and the Origin Note.

Archive Core integration

Canonical projects appear as PRX files. OPEN MENDALA, OPEN CARBON, OPEN CINEMA, and other aliases resolve through Archive Core rather than a private command list. Project counts and statuses are loaded from the shared manifest.

Emotional contract

The machine should feel welcoming, slightly magical, and genuinely usable. Nostalgia supports discovery rather than becoming a decorative skin over dead links.

Progressive enhancement

The startup sequence is skippable, reduced motion is respected, no audio is forced, and the standard Network remains available if the shell cannot load.
