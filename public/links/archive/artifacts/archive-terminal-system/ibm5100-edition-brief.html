PARALLAX ARCHIVE · DISCOVERY SHELL

IBM 5100 Archive Edition

A compact research-terminal experience that presents the archive as something discovered, cataloged, mounted, and inspected.

Historical boundary: this is a Parallax-built, historically inspired simulation. It does not run original IBM firmware or claim complete hardware emulation.

Role

The IBM shell is the archive’s Discovery edition. It slows the visitor down, removes modern dashboard language, and treats every project as a research object with a stable catalog identity.

Interaction language

Projects appear as tape records. Visitors use commands such as CATALOG, LIST, LOAD, READ, RUN, EJECT, STATUS, and ENGINEER. Loading mounts a canonical record; reading inspects it within the restrained CRT; running opens the full Archive Record.

Display discipline

The interface follows a deliberately constrained text rhythm inspired by compact research terminals. Short lines, limited visible history, quiet phosphor color, and an engineer panel create focus without pretending to reproduce original machine software.

Engineer mode

Diagnostics expose Archive Core version, record count, content-pack count, fallback state, and the simulation boundary. The machine explains what is real, what is presentation, and what remains future emulation work.

Accessibility

Every command has a keyboard and touch path. Reduced motion skips startup pacing, direct project routes remain available, and the standard Network is always reachable.
